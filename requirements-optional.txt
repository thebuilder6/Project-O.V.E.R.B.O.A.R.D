# Optional dependencies.
#
# The core solver and the browser studio only need requirements.txt.
# These packages add:
#   --validate    the Immrax reachability gate (needs jax + immrax)
#   --push-hub    pushing a trajectory to a Pybricks hub (needs pybricksdev)
#
# Pinned to the pair the test suite runs against here: the Immrax inclusion
# rules and the JAX API move, and an unpinned install brings a stack whose
# numbers nobody measured. Raise both together and re-run the suite.
# jax 0.12.0 / immrax 0.3.8 are unmeasured here (jax 0.12.0 has no matching
# distribution) and break the tick propagation, so the pair below is the one
# measured to pass.
jax==0.6.2
immrax==0.3.6
pybricksdev
# The PDF renderer for the mat import: FIRST's field guide is a PDF, and
# the studio composes the mat picture from it. Without this the mat
# download says what to install and the two mat tests fail (KI-046).
pypdfium2
# bleak is imported directly by hub_ble.py to find the hub over Bluetooth.
# It arrives with pybricksdev, but it is a direct import, so it is named
# here (KI-046).
bleak
# scipy is imported by immrax.utils, which the envelope experiment uses for
# the Monte-Carlo check against the reachable set. Immrax declares shapely,
# pypoman and matplotlib but not scipy, so it is named here (KI-049).
scipy
